# Reproducibility map — AMMBEC Denver urban-methane paper

Everything in the manuscript is regenerated by the R toolkit. From `code/`:

```r
install.packages(c("ncdf4", "terra"))   # only external deps
Rscript run_all.R                        # runs steps 01–23
```

Outputs land in `MethaneData_outputs/` (CSVs) and `MethaneData_outputs/figures/` (PNGs).

## Building the documents (every number comes from the pipeline)

After `Rscript run_all.R`, build the three Word documents from the pipeline outputs:

```bash
cd manuscript          # where the *.js generators + build_docs.sh live
npm install docx       # one-time
bash build_docs.sh ~/MethaneData_outputs
```

Invoke it with `bash build_docs.sh` (not `./build_docs.sh`). When these files are
copied onto your machine the executable bit is not preserved, so `./build_docs.sh`
fails with "permission denied"; `bash build_docs.sh` sidesteps that. If you prefer
`./build_docs.sh`, run `chmod +x build_docs.sh` once first.

`paper_values.json` (every scalar the papers quote — fossil ranges, fluxes,
inventory anchors, correlations, counts) is written by R **script 21** during
`Rscript run_all.R`. `build_docs.sh` then runs the three Node generators, which
read that JSON plus `table1.csv` / `emission_estimates.csv` / the SI CSVs, so
**no number is hand-typed** — re-running the pipeline updates the documents
automatically.

| Document | Generator | Reads |
|---|---|---|
| `AMMBEC_manuscript_consolidated.docx` | `full_manuscript.js` | paper_values.json, table1.csv |
| `AMMBEC_SI.docx` (Figs S1–S2, Tables S1–S3, CDPHE/CSL context) | `si_document.js` | paper_values.json, ratio_method_flux.csv, closeloop_diagnostic.csv, qc_robustness.csv |
| `AMMBEC_equations_explained.docx` (equations as figures, plain-language) | `equations_doc.js` | — (self-contained reference) |

Notes:
- **Step 18 runs on your machine** (the GRA2PES 'total' archives are ~7–20 GB). Its two numbers are pasted into `config.R` (`E_CO_DENVER`, `E_CH4_GRA2PES`).
- **Step 20 overwrites** the plain Fig1/Fig4 that step 12 also draws, giving the basemapped versions used in the paper. If `terra` is absent, step 20 is skipped and step 12's non-basemap Fig1/Fig4 remain.
- `set.seed(42)` in `config.R` makes the bootstrap CIs in Table 1 deterministic.
- The manuscript document itself is assembled by `full_manuscript.js` (Node/docx-js); all the *content* it embeds is produced by the R scripts above. Ask if you want that ported to R `officer`.
