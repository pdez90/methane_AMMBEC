# Reproducibility map — AMMBEC Denver urban-methane paper

Every quantitative claim in the manuscript is regenerated by the R pipeline in
this repository. Run from the **project root** (the directory holding `config.R`):

```bash
export METHANE_DATA_DIR="$HOME/MethaneData"          # inputs; see README "Data availability"
export METHANE_OUT_DIR="$HOME/MethaneData_outputs"   # outputs

Rscript setup.R      # reports R version, optional packages, resolved paths
Rscript run_all.R    # stages 01 through 30
```

The core analysis needs **base R only** (R >= 4.0). Optional stages need `terra`,
`ncdf4`, `sf`, `png`, or `tigris`; `setup.R` reports which you are missing, and
`run_all.R` skips those stages with a message rather than failing. See the
dependency table in `README.md`.

Outputs land in `$METHANE_OUT_DIR` (CSVs, `paper_values.json`, `sessionInfo.txt`)
and `$METHANE_OUT_DIR/figures/` (PNGs). The small ones are also committed under
`results/` so the manuscript's numbers can be audited without the raw data.

`set.seed(42)` in `config.R` makes the leg-block bootstrap intervals deterministic.

## Inventory anchors (one-time preparation)

Scripts 16, 17 and 18 sum huge gridded inventories over the exact analysis box.
They are **not** part of `run_all.R`, so the main pipeline runs without the
multi-GB archives; their scalar results are recorded in `config.R`.

| Constant | Value | Script | Note |
|---|---|---|---|
| `E_CO_DENVER` | 121.5 Gg CO/yr | `18_gra2pes_boxsum_LOCAL.R` | GRA2PES v1.1 total CO, Jul 2023, 171 4-km cells. Primary anchor (box-consistent) |
| `E_CO2_DENVER` | 23,478 Gg CO2/yr | `16_vulcan_co2_boxsum.R` | Vulcan v4.0 fossil CO2, 2022, 2,755 1-km cells |
| `E_CO_NEI` | 291.5 Gg CO/yr | `17_nei_co_metro.R` | EPA 2020 NEI seven-county; ~4x the box, so an upper bound only |
| `E_CH4_GRA2PES` | 1.69 t/hr | `18_gra2pes_boxsum_LOCAL.R` | Box-consistent bottom-up methane, for comparison |

`make_metro_outline.R` is likewise one-time (needs `tigris`); its output, the
seven-county outline used by the Figure 1 inset, is committed.

## Stages deliberately excluded from `run_all.R`

- **05 (curtain flux) and 09 (summary merging those fluxes).** No flight supports
  a valid closed-loop or curtain flux, so these results are not reported. The
  scripts are retained for transparency rather than deleted, but excluded from the
  reproducible run so rejected numbers are never regenerated.
- **16, 17, 18, `make_metro_outline.R`.** One-time preparation, as above.

## The manuscript document

The Word manuscript and SI are maintained separately from this repository and are
**not** built by it. The pipeline's role is to emit every quantity they quote:
`results/paper_values.json` is the machine-readable digest of the headline values,
with the per-flight detail in `table1.csv`, `ratio_method_flux.csv`,
`emission_estimates.csv`, `beta_sensitivity.csv`, `beta_endmember_ARC.csv`,
`qc_robustness.csv` and the other files under `results/`. Any number in the
manuscript should be traceable to one of those files via the table above.
